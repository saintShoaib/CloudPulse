# 🚦 CloudPulse

### Real-Time Urban Intelligence System

CloudPulse is a responsive cloud-based dashboard that combines **real-time environmental data, cloud storage, and AI forecasting** in one platform.

### ⚡ How It Works

User selects a location  
↓  
Open-Meteo provides weather + air-quality data  
↓  
Python processes the data and calculates AQI  
↓  
IBM Cloudant automatically stores the readings  
↓  
Random Forest estimates the AQI ~1 hour ahead  
↓  
Streamlit displays live data, trends, predictions & analysis

### 🛠️ Built With

**Python** • **Streamlit** • **IBM Cloudant** • **Open-Meteo** • **Pandas** • **Scikit-learn** • **Random Forest** • **HTML/CSS/JavaScript**

### ✨ Highlights

🌦️ Live Weather & Air Quality  
🤖 AI-based AQI Forecasting  
🔎 Smart Location Search  
☁️ Automatic Cloud Storage  
📊 Pro Environmental Analysis  
📱 Mobile & Desktop Responsive UI

> **Note:** CloudPulse uses modelled Open-Meteo data. Its AQI is a project-level PM2.5 estimate and its AI forecast is an estimate, not an official CPCB reading or guaranteed prediction.
